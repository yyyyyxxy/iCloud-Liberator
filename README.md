## 💥 起因与核心痛点

很多人因换用安卓旗舰、自建 NAS、或打算给电脑硬盘做本地冷备份，想把 iCloud 里动辄 200GB ~ 1TB 的照片原片拷出来。但几乎所有人都会撞上两堵大墙：

* **大墙 1（电脑装不下）**：Mac 本地固态硬盘通常只有 256GB / 512GB，而 iCloud 图库动辄 300GB+，直接开“下载原件”本地硬盘立马爆仓瘫痪。
* **大墙 2（导出慢到怀疑人生）**：好不容易把图库放到了外接盘上，在官方照片 App 里点击「导出未修改的原件」到通用的 ExFAT 移动硬盘时，传输速度居然只有可怜的 **`10 ~ 12 MB/s`**！300GB 的照片要烤 **整整 10 个小时以上**，期间伴随严重发热、风扇狂转、大视频频繁假死。

**本项目为你提供一套从云端下载到跨平台原片提取的闭环救赎方案。**

## ☁️ 阶段一：云端全量下载指南（不占 Mac 本地磁盘）

> [!IMPORTANT]
> **核心技巧**：利用 Mac「照片」App 支持**外置图库并指定为系统图库**的特性，让 iCloud 直接将几百 GB 的高清母片下载到外接移动固态硬盘（SSD）中，完全不占用 Mac 本地寸土寸金的内置磁盘！

### 步骤 1：准备外接下载盘（推荐 APFS 格式）
1. 准备一块高速移动固态硬盘（如 512GB 或 1TB SSD，命名示例：`WorkDrive`）；
2. 打开 Mac 的「磁盘工具 (Disk Utility)」，将这块外接盘格式化抹掉为 **`APFS`** 格式（苹果原生格式对 iCloud 同步下载最为稳定高效）。

### 步骤 2：创建或迁移图库到外接盘
1. **彻底退出照片 App**（快捷键 `Cmd + Q`）；
2. 打开 Mac 的「访达 (Finder)」，进入 `Macintosh HD -> 用户 -> 你的用户名 -> 图片`；
3. 将默认的 `Photos Library.photoslibrary`（照片图库）**直接拖动复制到外接移动硬盘中**；
   *(或者：按住键盘上的 `Option (⌥)` 键不放，同时点击 Dock 栏的「照片」App 图标，弹窗选择「新建图库...」，将位置直接选在外接盘上)*。

### 步骤 3：核心关键步！切换为「系统照片图库」
1. 按住 `Option (⌥)` 键启动照片 App，在弹出的列表中选中外接盘上的图库，点击「选取图库」；
2. 点击顶部菜单栏：**「照片」->「设置」（或快捷键 `Cmd + ,`）**；
3. 在「通用」标签页中，点击 **「用作系统照片图库」 (Use as System Photo Library)**（如果按钮呈灰色，说明当前已经生效）；
   > [!WARNING]
   > 只有设置为“系统照片图库”，苹果才允许该图库连接 iCloud 进行全量同步下载！

### 步骤 4：开启下载无损原件
1. 依然在照片设置窗口中，切换到 **「iCloud」** 标签页；
2. 勾选 **「iCloud 照片」**；
3. **务必选择单选框：「将原件下载到此 Mac」 (Download Originals to this Mac)**，千万不要勾选“优化 Mac 存储空间”！

### 步骤 5：保持挂机与防休眠
* 大批量原图从云端下载取决于你的宽带网速（300GB 约需 1~3 小时）；
* 此时打开终端，输入 `caffeinate -d` 按回车，可以防止 Mac 在合盖或闲置时进入睡眠；
* **下载完成标志**：在照片 App 主界面最底部，看到状态变为 **「刚刚与 iCloud 同步」 (Synced with iCloud Just Now)**，且不再有“正在下载 xxx 个项目”的提示，说明全量无损母片已 100% 躺在外接盘的 `.photoslibrary` 包中！

## 🐢 阶段二：为什么官方照片 App 导出慢成蜗牛？

全量原片下载完成后，大家通常会插上一块通用的 **ExFAT** 格式大容量硬盘，在照片 App 导出，但速度却只有 10MB/s。底层深层元凶有两个：

```mermaid
flowchart TD
    subgraph 官方照片App导出慢的本质
        A["官方照片 App<br/>单线程串行处理"] -->|几十KB极小切片 write()| B["macOS Sequoia / Sonoma<br/>FSKit 用户态 ExFAT 驱动"]
        B -->|频繁用户态与内核态 IPC 切换<br/>95% CPU 时间在空转等待| C["外接 ExFAT 移动硬盘<br/>速度暴跌至 10~12 MB/s"]
    end

    subgraph 本工具极速绕行的解法
        D["直接解析底层数据库<br/>Photos.sqlite"] -->|获取原文件名与实况关联| E["4MB 黄金大块缓冲<br/>+ 4~8 线程并发流式 I/O"]
        E -->|直接击穿 FSKit 上下文切换瓶颈| F["外接 ExFAT 移动硬盘<br/>满速跑满 350~380 MB/s!"]
    end

    style C fill:#ffebee,stroke:#c62828
    style F fill:#e8f5e9,stroke:#2e7d32
```

1. **macOS FSKit 用户态驱动的“紧箍咒”**：新版 macOS 把 ExFAT 驱动移至用户态空间。普通软件如果频繁用几十 KB 的小块去写入，每一次写入都会触发内核与用户态驱动的 IPC 上下文切换，性能暴跌 90% 以上；
2. **照片 App 单线程串行**：调用栈分析证实，照片 App 内部使用单线程队列一个个排队导出，遇到几百张碎照片或一个大视频，全卡在系统写入等待上。

## 🛡️ 四大核心保障：名称、实况、格式与隐私

许多人不敢用第三方脚本的原因是担心文件损坏或隐私泄露。本工具在底层严格设计了四大铁律：

### 1. 📛 文件名称绝对保真（绝无乱码 + 同名顺延保护）
* **摆脱乱码 UUID**：苹果底层物理文件名是乱码（如 `FB80E5FF....heic`），脚本通过 CoreData 数据库直接还原为你拍摄时的真实原名（如 `IMG_1659.HEIC`、`VID_20240616.mp4`）；
* **同名碰撞顺延**：iPhone 计数器重置导致的多张同名文件（如不同年份的两张 `IMG_0001`），自动遵循官方规则重命名为 `IMG_0001 2.JPG`，**绝不发生覆盖丢失**。

### 2. 🎞️ 实况照片（Live Photo）原生同名配对
实况照片在苹果底层就是两份独立原片。脚本提取后会保持**完全一致的基准名称**：
```text
📁 全量备份/
├── IMG_1659.HEIC     <-- 高清静态母片
├── IMG_1659.MOV      <-- 原生实况短视频 (与 HEIC 同名成对配对)
├── IMG_1660.DNG      <-- 相机 RAW / ProRAW 原片
└── VID_20240616.mp4  <-- 独立录制视频
```
保留了苹果原生的 `Content Identifier` 标识，进入安卓或 Windows 依旧血脉相连！

### 3. 🔒 隐私绝对安全隔离（隐藏相册 0 泄露）
* 脚本在 SQL 层面写死安全过滤规则：`WHERE ZHIDDEN = 0 AND ZTRASHEDSTATE = 0`；
* **隐藏相册（Hidden Album）与最近删除废纸篓物理级剔除**，绝不会有一张私密照片被错误打包拷贝出去；
* 脚本纯本地执行，无任何网络行为，100% 保护数据隐私。

### 4. 📅 拍摄时间戳精准回写
* 脚本提取文件后，利用操作系统内核 API 将文件的修改时间（`mtime`）自动重写为**当年的原始拍摄时刻**；
* 导入安卓手机或 Windows 查看时，**时间线、按月回忆完全准确，绝不会全部堆在“今天”**。

## 📱 阶段四：无缝导入安卓手机与 Windows 电脑

### 导入安卓手机（小米 / 华为 / OPPO / vivo / 三星 / 荣耀 / Google Pixel）：
1. 用 Type-C 数据线或 OTG 将 ExFAT 移动硬盘直接连接手机；
2. **方法 A（相册直读）**：打开手机自带相册，点击「设置 -> 从外部存储导入」；
3. **方法 B（文件管理器复制）**：使用手机自带「文件管理」，将移动硬盘里的照片文件夹直接复制进手机内部存储的 **`DCIM/Camera`** 目录；
4. **效果**：相册会自动完成索引，实况照片（Live Photo）长按即可直接播放动态效果，时间轴、地理位置完美还原！

### 导入 Windows 电脑：
* 将 ExFAT 硬盘插上 Windows 电脑即可免驱动直接秒读；
* 原片格式（JPG、PNG、MP4、MOV）均原生支持直接双击播放；
* 针对 `.heic` 格式，可在微软商店搜索安装免费的「HEIF 图像扩展」即可原生预览缩略图。

## ❓ 常见问题与避坑排查手册 (FAQ)

<details>
<summary><b>Q1: 为什么我的移动硬盘插在 Mac 上，测速只有 30~40 MB/s？</b></summary>
请排查你的 USB 拓展坞或转接头：许多廉价多功能拓展坞上的 USB 接口其实是 USB 2.0 协议（最高 480Mbps，实测 40MB/s）。请尽量将移动硬盘直连 Mac 的雷电/Type-C 口，或使用支持 USB 3.2 Gen 2 (10Gbps) 的正规拓展坞。
</details>

<details>
<summary><b>Q2: 导出中途我不小心拔掉硬盘或强制关闭了终端怎么办？</b></summary>
完全不用担心！本工具具备<b>内置断点续传特性</b>。重新插好硬盘并重新运行脚本，它会自动检测目标文件夹中已经完整写入的文件并秒级跳过，仅继续传输剩余未完成的部分。
</details>

<details>
<summary><b>Q3: 实况照片如果不想要那个伴生的 .MOV 视频，可以只要静态照片吗？</b></summary>
实况照片在拍照瞬间就是一张静态图加一段 3 秒视频。保留 .MOV 才能在安卓端还原动态效果；如果你确实不想要动态视频，只需在传输完成后在文件夹里按类型排序，批量删除或搜索 <code>.MOV</code> 即可。
</details>
